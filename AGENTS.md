# TokenMaster agent instructions

**The instructions are in `CLAUDE.md`, in this same directory. Read that file.**

This one is a pointer and holds no rules of its own. Both agents that work in this repository
read the same file, because the alternative is two copies of the same rules drifting apart —
and that is the specific mistake this repository has already made and documented: four
narrative documents once absorbed more edits than the most-edited source file and still
contradicted each other.

If a rule appears to be missing, it is missing from `CLAUDE.md`, and that is where to add it.
